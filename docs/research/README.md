# Research records

One file per topic (`<topic>.md`), written under the hard rule in [../agents/research.md](../agents/research.md) whenever a conclusion affects design, dependencies, or public API.

Each record states the conclusion, links its sources (labelled `official docs` / `release notes` / `upstream source` / `issue` vs `blog inference`), gives the research date and versions checked, and lists the impact and open questions.
